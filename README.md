# AI Text Cleaner for Microsoft Word

A Microsoft Word model designed to quickly clean up text by strange character left by your favourite AI tools like ChatGPT, Claude, Gemini, and others.

## What this add-in does
When copying AI-generated text, hidden characters and unwanted formatting often get pasted into your document. This tool fixes that by removing:
* Non-breaking spaces and invisible characters (zero-width spaces).
* Leftover formatting symbols (such as stray asterisks, hashtags, or unusual dashes).
